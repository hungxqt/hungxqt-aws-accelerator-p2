# Terraform AWS

## EC2

1. `aws_instance` block
    
    ```hcl
    resource "aws_instance" "terraform_ec2" {
        ami           = var.ami
        instance_type = var.instance_type
        count = var.instance_count
        
        tags = {
            Name = "Terraform EC2 Instance"
        }   
    }
    ```
    
    - `associate_public_ip_address = true` ⇒ When set to **true**:
        - The EC2 instance will be **assigned a public IP address at launch time**
        - This happens **even if the subnet setting is different**

## VPC

1. `aws_vpc` block
    
    ```hcl
    resource "aws_vpc" "terraform_vpc" {
        cidr_block = var.cidr_block // 10.0.0.0/16
    
        enable_dns_hostnames = true
        enable_dns_support = true
    
        tags = {
            Name = "terraform-vpc"
        }
    }
    ```
    
2. `aws_subnet` block
    
    ```hcl
    resource "aws_subnet" "terraform_public" {
        count = var.public_subnet_count
    
        vpc_id = aws_vpc.terraform_vpc.id
        cidr_block = cidrsubnet(var.cidr_block, 8, count.index)
    
        tags = {
            Name = "public-subnet-${count.index + 1}"
        }
    }
    
    resource "aws_subnet" "terraform_private" {
        count = var.private_subnet_count
    
        vpc_id = aws_vpc.terraform_vpc.id
        cidr_block = cidrsubnet(var.cidr_block, 8, var.public_subnet_count + count.index)
    
        tags = {
            Name = "private-subnet-${count.index + 1}"
        }  
    }
    ```
    
    - `map_public_ip_on_launch = true` ⇒ When this is set to **true**: Any EC2 instance launched in this subnet will **automatically receive a public IP address**
3. `aws_internet_gateway` block
    
    ```hcl
    resource "aws_internet_gateway" "terraform_internet_gateway" {
        vpc_id = aws_vpc.terraform_vpc.id
    
        tags = {
            Name = "terraform-internet-gateway"
        }
    }
    ```
    
4. `aws_route_table` block
    
    ```hcl
    resource "aws_route_table" "terraform_route_table_public" {
        vpc_id = aws_vpc.terraform_vpc.id
    
        tags = {
            Name = "terraform-public-route-table"
        }
    }
    ```
    
5. `aws_route` block
    
    ```hcl
    resource "aws_route" "internet_access" {
        route_table_id = aws_route_table.terraform_route_table_public.id
        destination_cidr_block = "0.0.0.0/0"
    
        gateway_id = aws_internet_gateway.terraform_internet_gateway.id
    }
    ```
    
6. `aws_route_table_association` block
    
    ```hcl
    resource "aws_route_table_association" "public_assoc" {
        count = var.public_subnet_count
    
        subnet_id = aws_subnet.terraform_public[count.index].id
        route_table_id = aws_route_table.terraform_route_table_public.id
    }
    ```
    
7. `aws_availability_zones` data block
    
    ```hcl
    data "aws_availability_zones" "available" {
        state = "available"
    }
    ```
    
    This is the **data source** in Terraform, which is used to retrieve information from AWS instead of creating new resources:
    
    - It get the list of Availability Zones (AZs) in the current region
    - Only get the AZ with `available` state
    
    Common output
    
    | Attribute | Ý nghĩa | Value |
    | --- | --- | --- |
    | `names` | Danh sách tên AZ (vd: ap-southeast-1a, 1b...) |  |
    | `zone_ids` | ID của AZ (vd: apse1-az1) |  |
    | `group_names` | Nhóm AZ (ít dùng) |  |
    | `all_availability_zones` | Bao gồm cả AZ không available | `true` / `false`  |
    | `state` | Trạng thái của AZ | `available` , `information` , `impaired`  |
    | `filter` | Dùng để lọc nâng cao |  |
    
    Use `availability_zone = data.aws_availability_zones.available.names[count.index]` / `availability_zone_id = data.aws_availability_zones.available.zone_ids[count.index]` to get the data.
